## 🚀 Featured Cybersecurity Projects

### 🔎 [Python Port & Banner Scanner](https://github.com/SAQ8er/Vulnerability-Scanner)
**Python • Sockets • CLI**

An educational Python script that checks a defined list of TCP ports and tries to retrieve service banners for basic reconnaissance. Intended only for systems the operator is authorized to test. This is a **basic port scanner, not a comprehensive vulnerability assessment engine**.

### 🌐 [Network Traffic Analysis Report](https://github.com/SAQ8er/Network-Traffic-Analysis-report)
**Wireshark • TCP/IP • PCAP**

A technical report covering packet inspection, indicators of suspicious traffic, clear-text credential exposure, network security risks, and recommendations for improving monitoring and transport encryption.

### 🔐 [Secure Login System](https://github.com/SAQ8er/Secure-Login-System)
**C++ • Authentication • Educational Security Prototype**

A C++ console prototype demonstrating password hashing and salting concepts, account lockout after repeated login failures, and simulated OTP verification. The example uses `std::hash` and displays OTPs in the console, so it is **not suitable for production use**.
